# Chexplained Web App

Basic Next.js app for the Chexplained web experience.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Scripts

- `npm run dev` starts the local development server.
- `npm run build` creates a production build.
- `npm run start` starts the production server.
- `npm run lint` runs ESLint.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- ESLint

## Source

Start with `app/page.tsx` for the home page and `app/globals.css` for global styling.
